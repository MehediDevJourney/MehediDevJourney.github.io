# 🎨 Mehedi Dev - Modern Portfolio Website

A modern, responsive, and beautifully designed portfolio website built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- **Responsive Design**: Fully responsive and mobile-friendly
- **Modern Aesthetics**: Dark theme with gradient accents
- **Smooth Animations**: Engaging scroll animations and transitions
- **Performance Optimized**: Fast loading and smooth interactions
- **SEO Friendly**: Semantic HTML and meta tags
- **Cross-browser Compatible**: Works on all modern browsers
- **Accessible**: WCAG compliant markup

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # Main stylesheet
├── script.js           # JavaScript functionality
└── README.md           # Documentation
```

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins, Sora)
- **Design**: Modern UI/UX principles

## 📱 Sections

1. **Navigation**: Fixed header with smooth scrolling
2. **Hero Section**: Eye-catching introduction
3. **About**: Personal introduction and statistics
4. **Skills**: Technical skills organized by category
5. **Projects**: Showcase of featured projects
6. **Contact**: Contact information and contact form
7. **Footer**: Social links and copyright

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/MehediDevJourney/MehediDevJourney.github.io.git
cd MehediDevJourney.github.io
```

### View the Website

Simply open `index.html` in your web browser or deploy to GitHub Pages.

## 🎨 Customization

### Change Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... other colors ... */
}
```

### Update Content

Edit the following sections in `index.html`:

- **Hero Section**: Update name and subtitle
- **About Section**: Modify personal information
- **Skills Section**: Add/remove skills and technologies
- **Projects Section**: Update project cards with your work
- **Contact Section**: Add your actual contact information

### Modify Projects

Each project card can be customized:

```html
<div class="project-card">
    <div class="project-image">
        <i class="fas fa-icon-name"></i>
    </div>
    <div class="project-content">
        <h3>Project Name</h3>
        <p>Project description</p>
        <div class="project-tech">
            <span>Technology 1</span>
            <span>Technology 2</span>
        </div>
        <a href="project-url" class="project-link">
            View Project <i class="fas fa-arrow-right"></i>
        </a>
    </div>
</div>
```

### GitHub Pages

1. Push your changes to the repository
2. Go to Settings → Pages
3. Select the branch to deploy (usually `main`)
4. Your site will be live at `https://username.github.io`
